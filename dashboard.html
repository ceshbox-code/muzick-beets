Обработка музыки

Выберите режим и папку. Перед запуском панель объяснит, что произойдёт с файлами.

1. Импорт в отдельную библиотеку

Создаёт обработанную копию в целевой папке. Исходная коллекция доступна только для чтения.

Безопаснее
Исходные файлы не перемещаются и не перезаписываются.

2. Работа без копирования

Обрабатывает файлы в выбранной папке. Теги внутри музыкальных файлов могут измениться.

Осторожно
Рекомендуем сначала попробовать на небольшой папке и убедиться, что есть резервная копия.

Текущие теги

Использует сведения, уже записанные в музыкальных файлах, и не выполняет автоматический поиск MusicBrainz.

MusicBrainz

Пытается найти соответствия в музыкальной базе данных. Результат зависит от точности исходных тегов и доступности сервиса.

Отдельные треки

Использует поиск по отпечатку для отдельных композиций; подходит не для каждого файла.

Проверка библиотеки

Диагностика помогает найти незаполненные поля и вероятные дубликаты. Сначала проверяем — ничего автоматически не удаляем.

Настройки панели
Настройте автоматические действия под себя. Изменения сохраняются для всех пользователей этой панели.
⚙


Автоматизация
Отключите любую функцию, если предпочитаете управлять ею вручную.


Автоматически обновлять состояние
Панель проверяет прогресс задачи и цифры библиотеки примерно каждые несколько секунд.


Автоматически загружать список папок
При открытии панели обновлять доступные папки для импорта и режима без копирования.


Подтверждать запуск обработки
Показывать окно с описанием действия перед запуском импорта или изменением тегов.


Компактные журналы
Показывать меньше строк журнала, чтобы экран оставался аккуратным.


Показывать технические журналы на главной
По умолчанию журналы доступны только в разделе «Проверка библиотеки».
